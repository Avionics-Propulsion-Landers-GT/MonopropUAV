# Solutions

Reference solutions. Try the exercises first; the point is the attempt, not the answer. The two files here import the
student starter from `../exercises/` and swap in a finished `controller()` (ex1)
and `student_weights()` (ex2), so they run with exactly the same flags as the
exercises and exercise the same grader. Expected numbers are in each file's
docstring. If a starter file changes, rerun both here before the next cohort.
